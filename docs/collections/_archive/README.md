# 原始采集资料归档

此目录保留整理前的资料，便于追溯和恢复。日常查找请进入[按系列整理的总目录](../README.md)。

- `snapshots/starter-2026-11-17/`：原第一批目录，内容和内部相对路径未改。
- `snapshots/expansion-2026-11-17/`：原第二批目录，内容和内部相对路径未改。
- `packages/`：原始两个 ZIP，未重新压缩或修改。

系列目录中的图片是这些快照图片的逐字节副本，不是重新下载或压缩的版本。路径映射与 SHA-256 记录在上级 `asset-path-mapping.json`，可运行上级 `scripts/verify.py` 验证。

原批次采集/打包脚本仅用于追溯历史采集过程，不会自动更新上级系列目录；要刷新整理结果，请核实输入后使用上级整理脚本。它不会覆盖已有不同内容的文件。
