# Windows Media Player Legacy

Windows桌面里的媒体库、可视化与播放记忆；区别于2022年新版Media Player。

3 个精选版本/节点，2 张图片。所有图片在 [images/](images/)；图片文件名尽量使用版本编号。

图片为原始参考素材，仍需审核授权、商标和隐私；不是每个版本都有匹配截图。
