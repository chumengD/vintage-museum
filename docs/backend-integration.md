# 后端检查与前端接入记录

检查日期：2026-11-17。以 `backend/src/main/java` 的实际实现为准。

## 已接入

| 功能 | 后端接口 | 前端处理 |
| --- | --- | --- |
| 注册、登录、当前账户、退出 | `/api/auth/register`、`login`、`me`、`logout` | 用户名登录，可选邮箱；HttpOnly Cookie；固定 30 分钟；注册后手动登录 |
| 系列列表、详情 | `GET /api/series`、`GET /api/series/{id}` | 解析包装对象与分页；首页、目录、选择器使用真实记录 |
| 创建系列及图标 | `POST /api/series` | multipart：JSON 类型的 `metadata` 和可选 `icon` 文件 |
| 图标读取 | `GET /api/series/{id}/icon` | 使用返回的 `iconUrl` |
| 创建版本 | `POST /api/series/{id}/versions` | 映射版本号、平台、日期、正文；未知日期可留空 |
| 版本链、详情 | `GET /api/series/{id}/versions`、`GET /api/versions/{id}` | 按平台展示、相邻版本导航，解析 `version` / `series` |
| 截图上传、列表、读取 | `POST/GET /api/versions/{id}/screenshots`、`GET /api/screenshots/{id}/image` | 单张 multipart 逐次提交；发布时上传、详情页补充、说明、放大预览 |

所有请求携带 Cookie 和 `X-App-Request: museum-web`。真实模式不启动 MSW，不用演示接口替代未实现功能。演示模式通过 `npm run dev:demo` 或 `npm run build:demo` 显式启用。

前端分类对应后端四种枚举：网络浏览/BROWSER、影音播放/MEDIA、即时通讯/INSTANT_MESSAGING、其他/OTHER；平台支持 Windows、macOS、Linux、Android、iOS、其他。

系列简介必填且最多 1000 字；版本说明最多 5000 字；截图说明最多 500 字。图标只支持 PNG/JPEG、2 MiB、宽高最多 2048；截图只支持 PNG/JPEG、5 MiB、宽高最多 8192、总像素最多 2000 万。前端约束文件类型与大小，后端负责真实解码、尺寸校验、重新编码和保存。

版本创建与截图上传不是同一事务。前端保留已创建版本 ID 与已成功上传进度，部分失败后只重试剩余图片，也可进入已发布详情继续补图。刷新发布表单会丢失未上传文件，需要重新选择。响应丢失时无法判断请求是否已落库；若后续要求严格避免重复写入，需要后端增加幂等键。

## 仍缺少的后端能力

以下功能在真实模式隐藏入口，不在前端页面标注开发状态；缺项仅记录在本文档中。

| 功能 | 缺少内容 |
| --- | --- |
| 收藏 | 收藏列表、添加、取消、当前收藏状态 |
| 评论与回复 | 列表、发表、回复关系及管理规则 |
| 草稿 | 创建、更新、读取、删除，按用户隔离 |
| 个人主页、资料编辑、公开档案 | 用户资料、个人发布索引、公开资料字段和查询 |
| 编辑系列/版本、修改历史、贡献记录 | 更新接口、权限、修订记录、贡献者查询 |
| 找回密码 | 申请、验证和重置流程；当前未实现邮件通知/验证码 |
| 系列标签、独立来源链接 | 模型及保存字段；真实创建表单暂不展示这些输入 |
| 独立版本图标、版本来源字段 | 版本图标暂沿用系列；来源链接可写入 Markdown 正文 |
| 截图修改/删除 | 当前只有上传、列表和读取 |

## 查询规模限制

后端已有分页，但没有搜索、分类/首字母筛选、最近更新排序参数，也不返回系列版本数量或年份范围。目前前端读取全部分页，并以最多 4 个系列并发读取版本，再完成筛选、计数与排序，避免遗漏第二页数据。适用于当前小规模馆藏；数据增长前应补服务端查询与聚合字段，将列表改为服务端分页，避免全量加载。

## 启动与验证

先在 `backend` 启动 Spring Boot（默认 `127.0.0.1:8080`），再在 `frontend` 执行 `npm run dev`，打开 `http://127.0.0.1:5173`。后端没有默认账号，先注册。已有开发数据库和 JWT 密钥无需改动。

前端自定义后端地址可在 `.env.development.local` 设置 `API_TARGET`。如更换前端端口/域名，需要同步后端 `MUSEUM_ALLOWED_ORIGINS`；默认 5173 已被允许。

验证结果：

- 后端 `mvn verify`：64 项测试通过，覆盖认证、迁移、系列、版本、图片校验与文件清理。
- 前端 `npm test`：15 项通过，新增真实接口格式、分页、枚举、multipart、错误反馈及未实现功能隔离测试。
- `npm run lint`、`npm run build` 通过。
- 演示模式 Playwright：桌面与移动尺寸共 10 项通过。
- 真实后端 Playwright：注册 → 登录 → 带图标创建系列 → 发布空日期版本 → 多截图上传 → 模拟第二张上传中断 → 续传且只创建一次版本 → 刷新读取 → 详情补图 → 首页展示 → 退出 → 匿名浏览，通过。

浏览器测试使用本机 Microsoft Edge（Chromium 内核）；后端联调使用隔离内存数据库与临时上传目录，未改动开发数据。复现命令与隔离启动方式见 `frontend/README.md`。

2026-11-17 新增资料库全量表单验证：13 个系列、78 个精选版本/节点、41 张截图及 5 个图标提交成功，15 项真实后端 Playwright 测试通过；详见 [资料库提交接口验证](collection-api-test.md)。
