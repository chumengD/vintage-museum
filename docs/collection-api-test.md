## 数据与接口的差异

以下为本轮测试适配规则，并非正式批量导入功能；原始资料未修改。

- 59 张素材中，41 张是有明确版本归属的截图，5 张是可上传的 PNG/JPG 品牌图标。其余 8 张 SVG 图标不上传，5 张历史参考图/产品参考图/照片不挂到具体版本。使用 QQ 的原始 SVG 验证：表单提示格式不支持，绕过表单直接提交接口返回 400。
- 接口只支持浏览器、影音、即时通讯和“其他”四种分类；操作系统、输入法、下载工具暂映射为“其他”。测试保留资料中的系列名称和介绍。
- 资料中的 `PC` 及未填写平台的桌面产品按 Windows 测试；微信沿用原始 iOS，Android 和 iOS 操作系统分别选择 Android、iOS。它们是本轮测试所选平台，不代表产品只支持该平台。
- 58 条精确到日的日期原样提交；20 条年份级或未知日期提交 `null`，时间线年份、日期精度和日期说明写入正文，未补造月日。
- 当前 API 没有独立的来源、素材审核状态、日期精度等字段；本轮将版本说明和来源链接写入 Markdown 正文。这套接口尚不能无损保存整个资料库模型。

## 复现与产物

隔离后端启动命令及端口配置见 [前端 README](../frontend/README.md)。启动后在 `frontend` 执行：

```powershell
$env:PLAYWRIGHT_CHANNEL = 'msedge'
npm run test:e2e:backend
```

- 测试源码：`frontend/e2e-backend/collections.spec.js`。
- 本次完整机器结果：`frontend/test-results/backend-results.json`（包含每个系列的创建 ID、版本 ID、日期、截图数量及请求状态附件）。
- 本次每个系列详情截图：`frontend/test-results/collections/` 下对应测试目录。
- 后续按上述命令运行还会生成 `frontend/playwright-report/backend/` HTML 报告，可用 `npx playwright show-report playwright-report/backend` 查看。

测试产物属于本地忽略文件，不提交仓库。测试完成后停止隔离后端，内存数据库随进程退出释放；本次结果不代表已经把资料导入日常开发数据库或线上环境。
